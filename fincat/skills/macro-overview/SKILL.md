# Macro Overview

分析 A 股整体市场环境。

## 工作流

1. **大盘指数**：`stock_quote(market="a")` 查沪深300、上证、创业板整体情况
2. **北向资金**：`stock_hsgt(direction="north")` 查近10日北向资金流向
3. **市场宽度**：通过涨跌停数量判断市场情绪（健康/狂热/恐慌）
4. **宏观新闻**：`stock_news(symbol="", max_results=3)` 查影响大盘的宏观要闻

## 输出格式

---
**A 股宏观 Overview {日期}**

**大盘状态**：
- 沪深300：{点位} ({涨跌%})
- 上证：{点位} ({涨跌%})
- 创业板：{点位} ({涨跌%})

**市场情绪**：{乐观/中性/谨慎} — {涨跌停数}只涨停/{跌停数}只跌停

**北向资金**：近10日累计 {净流入/净流出} {X}亿元

**关键变量**：
- 利率环境：{简要描述}
- 汇率：{简要描述}

**综合判断**：{大盘短期方向，1-2句话}
