# Earnings Analysis

分析个股的财务数据和业绩表现。

## 工作流

1. **财务指标**：`stock_financial(symbol="XXXXXX")` 查 PE、PB、ROE、毛利率、净利率等
2. **盈利能力**：重点看净利润增速、营收增速、毛利率变化
3. **估值对比**：与行业平均 PE/PB 对比，判断贵贱

**业绩趋势**：
- 营收同比：{X}% — {增长/下降}
