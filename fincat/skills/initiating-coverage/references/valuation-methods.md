# 估值方法论（Task 3 参考）

本参考文件定义了投行级估值方法，fincat 的 `initiating-coverage` skill 应遵循此方法进行估值分析。

---

## 1. 估值方法概述

### 1.1 主要估值方法

| 方法 | 适用场景 | 优缺点 |
|------|---------|--------|
| DCF（现金流折现） | 成长型公司、现金流稳定 | 高度依赖假设、适合内生成长公司 |
| 可比公司法（Comps） | 随时可用、快速参考 | 忽略成长性差异、容易受市场情绪影响 |
| 可比交易法（Precedents） | M&A 定价参考 | 数据难获取、并购溢价不一 |
| 股息折现模型（DDM） | 高分红、稳定型 | 不适合成长股 |
| PEG 估值 | 成长股快速参考 | 过于简单 |
| 净资产法（NAV） | 金融、地产、控股集团 | 不适合轻资产公司 |

**fincat 推荐组合**：DCF + 可比公司法（PE/PB）作为核心，辅以 PEG 和股息率参考。

## 2. DCF 估值（核心方法）

### 2.1 DCF 原理
```
内在价值 = Σ [ FCF_t / (1+WACC)^t ] + TV / (1+WACC)^n

其中：
- FCF_t = 第 t 年自由现金流
- WACC = 加权平均资本成本
- TV = 终值（Terminal Value）
- n = 预测期年份
```

### 2.2 WACC 计算

**公式**：
```
WACC = Ke × E/(D+E) + Kd × (1-T) × D/(D+E)

其中：
- Ke = 股权成本（CAPM）
- Kd = 债务成本
- E = 股权市值
- D = 债务面值
- T = 所得税率
```

**CAPM 股权成本**：
```
Ke = Rf + β × (Rm - Rf)

其中：
- Rf = 无风险利率（10 年国债收益率）= X%
- β = 系统性风险系数 = X
- (Rm - Rf) = 市场风险溢价 = X%
- **Ke = X% + X × X% = X%**
```

**WACC 简化计算**（A股常用）：
```
行业 WACC 参考：
- 消费：8-10%
- 科技：10-12%
- 金融：6-8%
- 医药：9-11%
- 周期：10-14%

本次估值采用 WACC = X%
```

### 2.3 终值（Terminal Value）计算

**Gordon 永续增长模型**（最常用）：
```
TV = FCF_n × (1+g) / (WACC - g)

其中：
- FCF_n = 第 n 年自由现金流
- g = 永续增长率（一般用 GDP 增速或行业增速，2-4%）
- WACC = 加权平均资本成本

TV = X × (1+X%) / (X% - X%) = X 亿元
TV 现值 = TV / (1+WACC)^n = X 亿元
```

**EV/EBITDA 退出倍数法**（作为交叉验证）：
```
假设永续期 EV/EBITDA = X 倍
TV = EBITDA_n × X
TV 现值 = TV / (1+WACC)^n = X 亿元
```

### 2.4 DCF 完整计算模板

**第一步：预测 FCF（年）**

| 项目（亿元） | Y1 | Y2 | Y3 | Y4 | Y5 |
|------------|---|---|---|---|---|
| 营收 | | | | | |
| 净利润 | | | | | |
| + 折旧摊销 | | | | | |
| ± 营运资本变动 | | | | | |
| - CAPEX | | | | | |
| **FCF** | | | | | |

**第二步：折现**

| 项目 | Y1 | Y2 | Y3 | Y4 | Y5 |
|------|---|---|---|---|---|
| FCF（亿元） | | | | | |
| 折现因子 | 1/(1+X%)^1 | 1/(1+X%)^2 | ... | | |
| **FCF 现值** | | | | | |

- 5 年 FCF 现值合计：X 亿元

**第三步：终值**

- 永续增长率 g：X%
- 终值：X 亿元
- 终值现值：X / (1+X%)^5 = X 亿元

**第四步：计算股权价值**

```
企业价值（EV）= Σ FCF现值 + TV现值 = X 亿元
+ 现金及等价物：X 亿元
- 债务：X 亿元
= 股权价值：X 亿元
÷ 总股本：X 亿股
**DCF 每股价值：X 元**
```

## 3. 可比公司法（Trading Comparables）

### 3.1 可比公司选择标准

**行业分类**：
- 同一子行业（如白酒、乳制品、酱油）
- 可比收入结构（to B / to C）
- 可比规模（营收 ±50% 以内）

## 6. 估值质量检查清单

- [ ] DCF 假设与行业特性匹配（成长股高 WACC，稳定股低 WACC）
- [ ] 永续增长率 g < WACC（否则模型失效）
- [ ] 可比公司来自同一行业（避免用银行股和非银行股互比）
- [ ] 使用 PE/PB 时，确认EPS和BPS为正
- [ ] 交叉验证：DCF 结果应与 Comps 结果相近（差异 <20%）
- [ ] 足球场覆盖了主要估值不确定性
- [ ] 明确标注各方法的假设前提和局限性
